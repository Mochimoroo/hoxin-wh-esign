# Hoxin WH e-Sign — แอปติดตั้งบนมือถือ / PDA / แท็บเล็ต (PWA)

หน้าเปิดแอปสำหรับระบบ **Hoxin Smart Material Issue** (ใบเบิก WH-005 · ใบนำเข้า WH-006 · DN SA-007)
ติดตั้งเป็นไอคอนบนหน้าจอ เปิดเต็มจอเหมือนแอป ไม่มีแถบเบราว์เซอร์

- ตัวระบบยังทำงานบน Google Apps Script เหมือนเดิม (ข้อมูล ลายเซ็น และสิทธิ์เข้าใช้งานไม่เปลี่ยน)
- แก้โค้ดระบบใน Apps Script แล้วแอปได้เวอร์ชันใหม่ทันที ไม่ต้องอัปโหลดไฟล์ชุดนี้ใหม่
- เปิดเอกสารตรงด้วย `?r=เลขที่เอกสาร` เช่น `.../?r=3310-2611070002` (นำไปทำ QR Code ได้)
- ถ้าเปลี่ยนลิงก์ Web App ให้แก้ `APP_URL` ใน `index.html` แล้วเปลี่ยน `CACHE` ใน `sw.js` เป็น v2

## ติดตั้งบนเครื่อง
- Android / Zebra / Keyence (Chrome): เปิดลิงก์ → เมนู ⋮ → **ติดตั้งแอป** หรือ **เพิ่มลงในหน้าจอหลัก**
- iPhone / iPad (Safari): ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
